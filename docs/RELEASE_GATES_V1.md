# StressKit v1 release gates

Public methods, benchmark results, and preprint must ship together or not at
all. Code availability is not evidence that external empirical gates passed.

## Implemented and locally passing

- versioned v1 public artifacts and schemas;
- byte-exact source anchors, model/prompt/request provenance, compatible-license
  records, and content-addressed repository/dependency/build code maps;
- deterministic built-in reducers for all seven supported claim profiles;
- raw utility recomputation against non-internals baselines;
- complete run-slot, dependency, signature, isolation, and digest-closure checks;
- separate Ed25519 plan/executor trust domains for public offline verification;
- global Holm–Bonferroni release verification;
- 2,000-trial bounded-profile calibration plus fresh-seed replication;
- 300-case planted compiler evaluation;
- optional PostgreSQL/S3/FastAPI control plane and outbound worker protocol;
- verified static evidence publisher with exclusions and abstentions;
- pass 3b omitted-term and retained Tier-B discovery ledger;
- adversarial CPU regression suite.

## Blocking public benchmark release

- Candidate registry contains 53 unresolved entries, but none has passed the
  typed pre-freeze closure. Current generated ledger records 15 exclusions,
  53 pending rows, and no eligible row. One excluded row records an agent-panel
  abstention because its frozen claim wording was unsupported. A second records
  complete slot accounting after one extractor supplied four invalid source
  quotes and the dependency-blocked critic was not run. A third records the
  ACDC Tracr-reverse panel: one extractor supplied three invalid anchors, one
  hit its frozen token limit, and the critic was not run. Pending rows still
  need SourceBundle, cross-provider agent panel, ClaimRecord, complete license
  closure, claim-map execution smoke, frozen AuditSpec, protocol review, and
  resource-estimate evidence as applicable.
- Pass 3b has 18 licensed code candidates, but manual scope review, full
  dependency licensing, claim maps, and smokes remain incomplete.
- No untouched silent final cohort or independent result cohort exists.
- No public `AuditBundle` has passed release-level verification.
- Flagship persona/misalignment artifact licenses remain unresolved; protocol
  therefore abstains and forbids substitution.
- External validation has not been obtained.
- Fourteen-day author-response windows have not started because no adverse
  named final decision exists.

Backward extension is not triggered yet. More than 20 current-window candidates
exist; eligibility blockers must be resolved before deciding whether fewer than
20 survive. If fewer than 20 become eligible, census extends backward one month
at a time under identical rules.

No public result or result-bearing preprint should be released while any blocker
above remains.

GPU allocation is intentionally downstream of registry freeze. Pre-freeze work
uses source retrieval, license review, claim compilation, CPU tests, and small
execution smokes where possible. Once a row freezes, its signed ResourcePlan
states exact GPU count, hardware class, wall time, and storage; no broad GPU
request is inferred from candidate compute-tier labels.
